# Images

The SVG illustrations here were made for this project and are free to use with it.

## Optional photos

The site works without photos. To add one, download a royalty-free image and save it under `public/images/photos/` with the exact name below. It appears automatically under a navy overlay, so text stays readable.

| File name | Where it appears | Search for |
|---|---|---|
| `hero.jpg` | Landing page hero | "Indian university campus" or "college building aerial" on Unsplash or Pexels |
| `auth.jpg` | Left panel on login and register | "students on campus" or "library study hall" on Unsplash or Pexels |

Use landscape images at least 1600 pixels wide and under 500 KB. Check each image's licence, and avoid photos that show recognisable people or real logos.
